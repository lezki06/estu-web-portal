# Eskişehir Technical University (ESTÜ) Web Portal Homework

A responsive, multi-page web portal created as part of the **BIM222 Web Technologies** coursework, designed to replicate and modernize the digital presence of Eskişehir Technical University (ESTÜ).

## 🚀 Features

- **Home (`index.html`)**: Latest announcements, university highlights, and campus banner.
- **University Information (`university.html`)**: Detailed overview of ESTÜ history, leadership, deans, quick statistics, contact details, and social media links.
- **Academics (`academics.html`)**: Comprehensive tables detailing Faculties, Institutes, and Vocational Higher Schools.
- **Student Portal (`students.html`, `login.html`)**: Information about academic calendar, student clubs, sports facilities, interactive campus map, and a mock login page.
- **Document Downloads (`documents.html`)**: Downloadable petitions, forms, and official PDF resources for students.
- **Campus Life (`campuslife.html`)**: Video tour of the campus, dining cafeteria information, and annual university events.

## 🛠️ Tech Stack & Dependencies

- **HTML5**: Semantic markup with full accessibility & SEO meta tags.
- **CSS3**: Custom modern styling, CSS Grid, Flexbox, and micro-interactions.
- **Bootstrap 5.3**: Responsive container system, typography, and utility classes.
